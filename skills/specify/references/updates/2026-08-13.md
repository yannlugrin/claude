# Doctrine changes — 2026-08-13

Nineteen entries from one project's four handoff review rounds and the
review of that run. Format and pass procedure: [../updates.md](../updates.md).

## U-001 — a spec amendment and its decision are one commit

- **Applies to:** running
- **Change:** the decision entry is still written before the amendment, but
  both land in a single governance-only commit — entry plus specification
  text, no code, the subject naming the decision. The entry lands alone only
  when the amendment belongs to a later step, and then says so. Two commits
  leave a state where the log asserts what the specification contradicts,
  which a resuming session reads as drift, and they put `git blame` on an
  amended line onto a diff with no reasoning in it.
- **Detect:** the project's read-only rule orders the entry logged "first"
  and the amendment in a separate or "dedicated" commit; or its history
  shows a decision commit followed by an amendment commit.
- **Remedy:** rewrite the rule in `CLAUDE.md`; check for an amendment left
  pending by the old pattern.

## U-002 — reviewer agents take the whole gated set

- **Applies to:** running
- **Change:** a read-only reviewer agent's never-run list is rule 9's entire
  *gated* set, not its deny set. A subagent cannot obtain the user's
  authorisation mid-run, so everything merely gated is, for it, forbidden.
- **Detect:** an agent's never-run enumeration is narrower than the `ask`
  tier of `.claude/settings.json`, or is absent.
- **Remedy:** widen the enumeration in every reviewer agent.

## U-003 — the line budget yields to the boundary

- **Applies to:** running
- **Change:** `optimize-memory` must not hold both "stay under 200 lines"
  and "never compress the action boundary" without saying which yields.
  The cap yields; trimming happens elsewhere; a file it cannot trim is
  reported rather than resolved by compressing safety text.
- **Detect:** the agent states both rules with no yield clause between them.
- **Remedy:** add the clause. (`CLAUDE.md` often already has it — the agent
  is the copy that gets missed.)

## U-004 — `.claude/refs/` for operator-supplied material

- **Applies to:** running
- **Change:** documents the user supplies as input — contracts of consuming
  systems, inventories, material owned by another project — live in
  `.claude/refs/`, never in `.claude/docs/`. The memory sweep owns the
  latter and will eventually fold or delete whatever sits there, and an
  operator-supplied reference is not the implementer's memory to compact.
  The sweep exempts `.claude/refs/` structurally: never compacted, never
  folded, never deleted; a stale pointer is a pointer to fix.
- **Detect:** reference material under `.claude/docs/`, protected only by a
  marker or by nothing; or no refs convention at all.
- **Remedy:** move what qualifies, update its pointers and read-triggers,
  and add the exemption to the sweep whether or not anything moves today.

## U-005 — the milestone ritual's fallback outlives the agents

- **Applies to:** running
- **Change:** `approve-step`'s milestone step must never name an agent that
  exists nowhere. When `state-reviewer` or `optimize-memory` is dropped, or
  the not-yet-adopted list is gone, the step points at the standing fallback
  (a fresh subagent briefed inline) — the compaction pass is mandatory
  whoever performs it, and this step is its only in-ritual trigger.
- **Detect:** the instantiated `approve-step` names an agent that is neither
  adopted nor on a not-yet-adopted list.
- **Remedy:** rewire the step to the fallback.

## U-006 — `settings.json` under the well-formedness check

- **Applies to:** running
- **Change:** the harness checks that `.claude/settings.json` parses, beside
  the skills and agents. It is the enforcement mechanism itself, so an edit
  that malforms it after the one-time bootstrap probe fails exactly as
  silently as a malformed skill.
- **Detect:** no check family covers the settings file.
- **Remedy:** extend the harness.

## U-007 — the git ask-tier is a classifier, not a list

- **Applies to:** running
- **Change:** anything that rewrites history (`commit --amend`, `rebase`),
  moves or deletes tags or branches, or destroys uncommitted or untracked
  work (`reset --hard`, `git clean`) asks first — and no allow pattern may
  silently admit one of them. The trap is a bare `git commit` allowance,
  which admits `--amend`.
- **Detect:** an allow pattern matching bare `git commit`; or history
  rewriting and untracked-file deletion absent from every tier.
- **Remedy:** propose a revised baseline **for the user's review** — the
  permission baseline is never within latitude.

## U-008 — the boundary enumerates its free side

- **Applies to:** running
- **Change:** "local and read-only is free" silently gates most of a normal
  development loop, which is local and full of writes. The boundary names
  the project's dev loop end to end and rules it free; destructive-local
  splits on blast radius — this project's own artifacts by name are free,
  an unscoped sweep reaching other projects on the host is gated. Git
  history and the working tree stay protected whatever the project.
- **Detect:** the boundary text gates ordinary local iteration, or frees a
  host-global destructive command.
- **Remedy:** restate the free side, then align the permission baseline
  (user's review, per U-007).

## U-009 — every shipped artifact class gets a check family

- **Applies to:** running
- **Change:** the check families cover everything the repository ships, not
  only what the specification named — third-party tools included, which
  arrive pinned with their version or digest recorded.
- **Detect:** an artifact class in the tree with no family covering it; a
  vendored tool with no pin.
- **Remedy:** extend the harness; log the additions.

## U-010 — `CLAUDE.md` carries the plan-step conventions

- **Applies to:** running
- **Change:** the plan-step entry shape (objective, spec sections,
  deliverables, how the user tests it with cost and cleanup when it crosses
  the boundary, status) belongs in `CLAUDE.md`. Later sessions extend the
  plan from `CLAUDE.md` alone.
- **Detect:** the conventions appear only in the plan's existing entries, by
  imitation.
- **Remedy:** state them in `CLAUDE.md`, within its budget.

## U-011 — the open-facts latitude split

- **Applies to:** running, where the specification carries open facts
- **Change:** resolving a fact the specification ordered settled at
  implementation splits in two: recording a verified fact is autonomous
  (entry and amendment in one commit, reported in the step summary), while
  any resolution that changes a requirement, a tier, a documented limitation
  or the decision to ship comes back to the user first. The items that
  always come back are named, not left to a criterion applied case by case.
- **Detect:** the project has open facts and no stated split, or a split
  that does not name its always-come-back items.
- **Remedy:** state it in `CLAUDE.md`; name the items.

## U-012 — the spec-work exclusion keys on path

- **Applies to:** running, where `.claude/spec-work/` survives
- **Change:** the harness exclusion for the specification phase's history
  keys on the path, not on tracked status — otherwise the rule depends on
  commit timing.
- **Detect:** the exclusion is written in terms of tracked files.
- **Remedy:** re-key it.
